# FREE LABO 売上導線診断メーカー

小規模店舗向けに、Instagram・LINE公式・予約導線の弱点を診断し、最後に FREE LABO への
LINE登録・無料相談につなげる診断ツールです。

デモ診断：**「店舗のLINE売上導線診断」**
> あなたのお店は、Instagramから予約・問い合わせを取りこぼしていませんか？

- スマホファースト / レスポンシブ
- 質問8問・選択式・1問ずつ表示・進捗バーあり
- 結果は4タイプ（総合スコア・課題・優先改善3つ・おすすめLINE活用・おすすめプラン）
- LINE登録 / 無料相談 / 診断ツール制作 への CTA
- 質問・選択肢・点数・結果文はすべて設定ファイルで差し替え可能
- 業種別に診断を後から追加できる構成
- 外部DBなし（ローカルの設定ファイルのみ）

## 診断ロジック

1. **総合スコア（0〜100点）**
   採点対象の各質問で選んだ選択肢の `points`（A=3〜D=0）を合計し、満点で割って100点換算。
   `scored: false` の質問（Q8「一番困っていること」）はスコアには含めず、方向性の判断のみに使います。

2. **結果タイプ判定（4タイプ）**
   各選択肢の `weights`（例 `{ D: 2 }`）を結果タイプごとに合計し、最も高いタイプを採用。
   同点のときは定義順（A→B→C→D）を優先します。Q8 は重みを大きくしており、
   「一番困っていること」が結果タイプに強く反映されます。

3. **優先して直すべき3つ**
   各質問の「達成度（選んだ点数 ÷ その質問の満点）」が低い順に並べ、
   `improvement`（改善ヒント）が設定されている質問の上位3つを自動表示します。

ロジック本体は `src/lib/scoring.ts` にまとまっています。

## 文言の差し替え方法

### 質問・選択肢・点数・結果文
`src/diagnoses/store-line.ts` を編集します（このファイルだけで完結）。

- 質問文・選択肢 … `questions[].text` / `questions[].choices[].label`
- 点数 … `questions[].choices[].points`（高い＝できている）
- 結果タイプの判定重み … `questions[].choices[].weights`
- 改善ヒント … `questions[].improvement`
- 結果4タイプの文章・課題・LINE活用・プラン … `resultTypes[]`

### ブランド名・CTAリンク・ボタン文言
`src/config/site.ts` を編集します。

- `SITE.brandName` … ブランド名
- `DEFAULT_CTA.lineUrl` … LINE友だち追加URL（例 `https://lin.ee/xxxx`）
- `DEFAULT_CTA.consultUrl` … 無料相談の窓口URL
- `DEFAULT_CTA.buildUrl` … 「自分のお店用に診断ツールを作る」問い合わせURL
- `CTA_LABELS` … ボタンの表示文言

> プロトタイプのため、CTAリンクの初期値は `#line` などのダミーです。
> 公開前に実URLへ差し替えてください。

## 業種別の診断を追加する

1. `src/diagnoses/store-line.ts` をコピーして新しいファイルを作成
   （例 `beauty-salon.ts`）。`slug` を一意な値に変更し、中身を書き換えます。
2. `src/diagnoses/index.ts` で import し、`DIAGNOSES` 配列に追加。

追加すると、トップページが自動で一覧表示に切り替わり、
`/diagnosis/<slug>` で個別に開けるようになります。画面側のコード変更は不要です。
